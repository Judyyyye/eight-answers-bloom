# Eight Answers Bloom

请帮我创建一个名为「今天测点啥」的中文趣味测试网站。

第一个测试产品叫「你是什么花？」。

网站要求：

使用中文，优先适配手机端，同时兼容电脑端。

整体风格年轻、可爱、有设计感，带一点梦幻和文艺气息。

主色调使用奶油白、浅粉色、淡紫色和柔和绿色。

首页包含品牌名称「今天测点啥」、测试标题「你是什么花？」、一句介绍「每个人都有自己的盛开方式」、测试说明「8道题，找到与你气质最接近的那一朵花」和开始测试按钮。

首页要有精致的花卉插画或装饰，整体简洁，不要过度堆砌元素。

创建完整的8道单选题答题流程，每次只显示一道题，包含进度条、上一题和下一题按钮。

暂时不要添加登录、数据库、支付功能，也不要要求用户填写个人信息。

请使用清晰、可维护的组件结构，方便以后增加其他趣味测试。

请先完成网站的首页和答题页面，并确保按钮可以正常使用。
